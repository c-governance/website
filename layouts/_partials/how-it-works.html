How it works

A state machine is a traditional way to express logic. States and events are calculated in individual threads, in memory, and shared by a database. See the whitepaper.

This is realized by microservices that are called populators and generators. Both are generic microservice templates that can be used to process data or calculate events. In combination, they can be used to build state machines.
